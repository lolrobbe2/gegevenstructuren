# Algorithm

> `Set of Instructions`

## What?

> A `set of instructions` to `solve` a certain `computational problem`

## DATA (IO)

> Receives a set of `inputs` and `produces` and `output`.

## Kind?

We seek algorithms that are `correct` and `efficient` while being `easy` to implement.

## Examples

> - sorting
> - data storage
> - searching
> - path finding

## Ever Evolving

> Algorithms are `not a finished product`,they can be `implemented` in `every programming language` on every machine.

## End Goal

> Our goal is not to learn a set of recipes by hard, instead we should learn `general problem solving techniques` that allow us to `solve new problems` not encountered before.
>
> - Divide-and-conquer
> - Randomized algorithms
> - Greedy approaches
